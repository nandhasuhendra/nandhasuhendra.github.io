## Overview

A personal website that doubles as a technical blog. Built with Jekyll for static site generation and Tailwind CSS for styling, deployed on GitHub Pages with zero infrastructure cost.

## Key Features

- **Blog**: Posts on software engineering, Ruby on Rails architecture, and cross-language engineering
- **Projects**: Showcase of personal and professional work
- **Tools**: A curated list of tools and services used daily for software development
- **SEO**: Full OpenGraph, JSON-LD structured data, sitemap, and RSS feed support

## Tech Highlights

- Jekyll collections for structured content (posts, projects)
- Lucide Icons with Simple Icons CDN for brand logos
- Client-side post filtering and pagination with vanilla JavaScript
- Syntax highlighting via highlight.js with GitHub Dark theme
- Social links: GitHub, LinkedIn, Threads, Instagram
