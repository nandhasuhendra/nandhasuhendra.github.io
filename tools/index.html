Tools

Software, services, and gear I use daily for backend development, testing, and debugging.

Languages

Ruby

Primary language for backend services and automation scripts

Go

For performance-critical services and distributed systems

SQL

PostgreSQL & MySQL for relational data modelling and queries

Sorbet

Static type checker for Ruby — catches type errors before runtime

Frameworks & Libraries

Ruby on Rails

Main framework for building web APIs and full-stack apps

dry-rb

dry-validation, dry-monads, dry-system for strict domain logic

Tailwind CSS

Utility-first CSS for building UIs fast without writing custom styles

Sidekiq

Background job processing for Rails — reliable, fast, Redis-backed

Devise + JWT

Authentication and token-based authorization for Rails APIs

Databases

PostgreSQL

Primary relational database — robust, feature-rich, production-ready

Redis

Caching, session storage, and Sidekiq job queue backend

MySQL

Used across legacy and existing production services at work

Testing

RSpec

BDD test framework for Ruby — unit, integration, and request specs

FactoryBot

Test data factories — clean, flexible fixture replacement for RSpec

Faker

Generates realistic fake data for tests and seeds

DevOps & Infrastructure

Docker

Containerised dev environments and deployment pipelines

GitHub Actions

CI/CD pipelines — automated tests, linting, and deployments

Kubernetes

Container orchestration for production service deployments

AWS

EC2, S3, RDS, and CloudWatch for cloud infrastructure

Observability & Monitoring

Sentry

Error tracking and performance monitoring for production apps

Datadog

APM, dashboards, and distributed tracing across services

OpenTelemetry

Vendor-neutral instrumentation for traces, metrics, and logs

Editor & Daily Tools

VS Code

Main editor with Ruby LSP, GitLens, and REST Client extensions

iTerm2 + zsh

Terminal setup with Oh My Zsh, aliases, and custom prompt

TablePlus

Native database GUI for querying PostgreSQL, MySQL, and Redis

Postman

API development and testing — collections, environments, and mocking

Git + GitHub

Version control, code reviews, and project collaboration

Figma

Design handoff and UI spec review during feature development
